# Luciano's Library

A thing I made to put various things in one place: mini-books on work tools, interviews, hiring, mentoring and a few theories, written since 2024 and still changing.

Read it at [minibooks.lucianoadonis.com](https://minibooks.lucianoadonis.com).

## Run it

Needs Node 22.23 or newer.

```bash
make install
make dev       # http://localhost:4321
make check     # everything CI runs before a deploy
```

Built with [Astro](https://astro.build), searched with [Pagefind](https://pagefind.app), set in [Alegreya](https://fonts.google.com/specimen/Alegreya). Icons from [Lucide](https://lucide.dev) (ISC).

How to add a book or a chapter: [CONTRIBUTING.md](CONTRIBUTING.md). How the writing should sound: [VOICE.md](VOICE.md).
